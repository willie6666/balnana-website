---
title: 从 Settle Up 导入
description: 把群组从 Settle Up 搬到 Balnana，连同支出、付款与余额。
---

从 Settle Up 过来的吗？你的群组可以连同历史记录一起搬过来。

1. 在 Settle Up 中，把群组导出为 **CSV**。
2. 在 Balnana 中，选择**新建群组 → 导入**，再选择该文件。

支出、付款与成员都会一起带过来，余额保持不变。

## 退款与收入

导入会保留退款与收入：支出统计会扣除退款并排除收入，而余额仍包含每一笔交易。

:::note
在 Balnana 开始记录每笔交易方向之前导入的群组，支出统计会不正确。要修正，请把原始 CSV 再导入成一个新群组；升级无法从旧的余额数据推算出缺少的方向。
:::

Balnana 也可以在 App 中把任何群组导出为 CSV。
