	<Card title="用 Docker 启动" icon="rocket">

	</Card>
	<Card title="在网页上调整设置" icon="setting">

	</Card>
	<Card title="选择加入群组的方式" icon="open-book">
		用私人链接邀朋友加入，不用注册。也能开启账号模式，通过密码、Google 或 OpenID Connect 登录。
	</Card>
