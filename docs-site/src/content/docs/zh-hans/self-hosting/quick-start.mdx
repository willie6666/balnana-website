Balnana 需要一个服务器程序和 PostgreSQL 数据库。项目里的 Docker Compose 文件会一起启动这两个服务，网页版 App 也已经包含在里面。

## 需要准备

- 一台装有 **Docker** 与 **Compose 插件**的机器。
- 一份 [Balnana 仓库](https://github.com/willie6666/balnana)。

## 启动服务器

<Steps>

1. 从示例创建配置文件：

   ```bash
   cp .env.example .env
   ```

2. 打开 `.env`，至少设置 `POSTGRES_PASSWORD`。用一串足够长的随机值即可：

   ```bash
   openssl rand -hex 24
   ```

   密码中请避免使用 `$`，因为 Compose 会把它当成变量；或改写成 `$$`。

3. 构建并启动所有服务：

   ```bash
   docker compose up -d --build
   ```

   启动时会自动执行数据库迁移。

4. 打开 `http://localhost:8080`。可用 `.env` 里的 `BALNANA_PORT` 更改端口。

</Steps>

## 设置管理员密码

新服务器第一次被打开时，App 会把用户带到 `/admin` 设置管理员密码。请在服务器启动后马上完成这一步。

设置密码时，还需要输入服务器日志中的**设置码**，避免其他访客先设好密码。用以下命令查看设置码：

```bash
docker compose logs balnana
```

<Aside type="tip">
	所有设置都附注释列在 `.env.example` 中。标有 `[admin]` 的设置之后也能在 `/admin` 修改，无需重启。
</Aside>
