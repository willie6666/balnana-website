---
title: 僅供檢視連結
description: 分享一個任何人都能檢視群組的連結，不需要帳號，也無法變更任何內容。
---

群組本身的連結可以用來修改群組，僅供檢視連結則只能查看。任何人開啟後，都能在瀏覽器裡看到群組。他們不需要帳號，也不會加入群組。

例如，可以把旅行最後的餘額給群組外的人看，或讓大家隨時查看共同費用的清單。

在開啟了[方案](/docs/zh-hant/self-hosting/plans-and-payments/)的伺服器上，僅供檢視連結需要包含此功能的方案。沒有的話，設定會顯示**需要升級方案**，並開啟方案頁面。

## 建立連結

1. 開啟群組，前往**群組設定 → 分享 → 僅供檢視連結**。
2. 在**更新方式**選擇連結的行為：
   - **持續更新**：每次開啟時都顯示群組目前的狀態。
   - **快照**：顯示群組現在的狀態，之後不再變動。
3. 在**顯示內容**開啟要讓人看到的項目。
4. 在**有效期限**可以選擇最後一天。留空的話，連結會一直有效，直到你停用為止。
5. 選擇**建立連結**，再複製、分享連結，或出示 QR 碼。

每個群組同時只能有一個僅供檢視連結。

誰可以管理取決於伺服器，和[群組密碼](/docs/zh-hant/guides/group-password/)一樣：

- **連結模式**：任何能開啟這個群組的人。
- **帳號模式**：群組的任何成員，登入自己的帳號即可。

## 顯示內容

| 設定 | 顯示 | 預設 |
|---|---|---|
| **餘額** | 每個人的餘額，以及結清所需的付款 | 開 |
| **支出** | 支出清單，可以搜尋 | 開 |
| **支出統計** | 支出圖表 | 開 |
| **支出備註** | 每筆支出的備註 | 關 |
| **支出地點** | 每筆支出的地點 | 關 |
| **收據照片** | 收據照片 | 關 |

餘額、支出與支出統計至少要開啟一項。備註、地點和收據照片只會在支出裡顯示，所以需要開啟**支出**。收據照片只有持續更新的連結才能顯示。

這些設定之後都可以變更，連結的網址不會改變。

## 快照

快照在建立連結時產生。之後新增的支出與變更都不會出現。若要顯示，請停用連結再建立新的連結。

## 停用連結

選擇**停用連結**後，連結會立即對所有持有者失效。新的連結會是不同的網址。

設有最後一天的連結會在當天結束時失效，之後開啟的人會看到**此連結已過期**。

如果群組的方案不再包含僅供檢視連結，連結會暫停而不是被刪除：開啟的人會看到**此連結已暫停**，等方案再次包含此功能後就會恢復。

## 隱私

- 任何持有連結的人都能看到它顯示的內容，請像分享群組本身的連結一樣謹慎。
- 群組密碼不適用於此連結。僅供檢視連結是另一個獨立的連結，無法變更任何內容。
- 在聊天 App 中分享連結時，預覽只會顯示這是一個 Balnana 群組，不會出現群組名稱。
- 群組的動態會記錄誰建立、變更或停用了連結。
