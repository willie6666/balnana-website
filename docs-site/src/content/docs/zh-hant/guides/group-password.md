---
title: 群組密碼
description: 透過連結開啟群組前先要求輸入密碼，只有連結就不夠了。
---

只要有群組的連結，任何人都能開啟它。設定群組密碼後，只靠連結已無法進入群組：Balnana 會先要求輸入密碼。

## 設定密碼

1. 開啟群組，前往**群組設定 → 分享 → 群組密碼**。
2. 輸入密碼，再選擇**儲存**。
3. 把密碼告訴群組的人，並和連結分開傳送。

誰可以設定取決於伺服器：

- **連結模式**：任何能開啟這個群組的人。
- **帳號模式**：群組的擁有者。群組已經沒有擁有者時，任何已登入自己帳號的成員都可以。

之後要變更或移除密碼，再次選擇**群組密碼**即可。

## 開啟設有密碼的群組

從連結開啟群組的人會看到**這個群組設有密碼**，輸入密碼後選擇**開啟群組**。連結模式的所有群組都是這樣；帳號模式中[任何有連結的人都能開啟](/docs/zh-hant/self-hosting/access-and-sign-in/#帳號模式)的群組也一樣。

每台裝置只要輸入一次，之後就會記住這個群組。在設定密碼之前就已經在這台裝置上使用群組的人，也同樣要輸入一次。

已登入自己帳號的成員不需要密碼。

猜錯密碼的次數有限制，和登入密碼一樣。

## 變更密碼

設定新密碼後，所有用舊密碼開啟過群組的裝置都會被登出，只有變更密碼的那台裝置除外。這些裝置的群組清單會把群組顯示為**這個群組設有密碼**，直到有人在那台裝置上輸入新密碼為止。

## 移除密碼

選擇**群組密碼 → 移除**。之後只要有連結，任何人都能再次開啟群組。

## 重設連結

**重設連結**會建立新連結，舊連結將失效。密碼不會改變，重設連結的那台裝置也會保持解鎖。請把新連結和密碼分享給需要繼續使用的人。

:::caution
如果密碼和連結一起傳送，密碼就沒有作用。請用其他方式告知，例如當面告訴對方，或在另一個聊天室傳送。
:::
