---
title: 從 Settle Up 匯入
description: 把 Settle Up 群組匯入 Balnana，保留原本的支出、付款與餘額。
---

已經在用 Settle Up 的話，可以直接匯入原本的群組，不用重新記帳。

1. 在 Settle Up 中，把群組匯出為 **CSV**。
2. 在 Balnana 中，選擇**新增群組 → 匯入**，再選取該檔案。

支出、付款與成員都會一起帶過來，餘額保持不變。

## 退款與收入

匯入會保留退款與收入：支出統計會扣除退款並排除收入，而餘額仍包含每一筆交易。

:::note
在 Balnana 開始記錄每筆交易方向之前匯入的群組，支出統計會不正確。要修正，請把原始 CSV 再匯入成一個新群組；升級無法從舊的餘額資料推算出缺少的方向。
:::

Balnana 也可以在 App 中把任何群組匯出為 CSV。
