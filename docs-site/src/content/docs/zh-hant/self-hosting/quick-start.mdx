Balnana 需要一個伺服器程式和 PostgreSQL 資料庫。專案裡的 Docker Compose 檔案會一起啟動這兩個服務，網頁版 App 也已經包含在裡面。

## 需要準備

- 一台裝有 **Docker** 與 **Compose 外掛**的機器。
- 一份 [Balnana 儲存庫](https://github.com/willie6666/balnana)。

## 啟動伺服器

<Steps>

1. 從範例建立設定檔：

   ```bash
   cp .env.example .env
   ```

2. 開啟 `.env`，至少設定 `POSTGRES_PASSWORD`。用一串夠長的隨機值即可：

   ```bash
   openssl rand -hex 24
   ```

   密碼中請避免使用 `$`，因為 Compose 會把它當成變數；或改寫成 `$$`。

3. 建置並啟動所有服務：

   ```bash
   docker compose up -d --build
   ```

   啟動時會自動執行資料庫遷移。

4. 開啟 `http://localhost:8080`。可用 `.env` 裡的 `BALNANA_PORT` 更改連接埠。

</Steps>

## 設定管理員密碼

新伺服器第一次被開啟時，App 會把使用者帶到 `/admin` 設定管理員密碼。請在伺服器啟動後馬上完成這一步。

設定密碼時，還需要輸入伺服器記錄中的**設定碼**，避免其他訪客先設好密碼。用以下指令查看設定碼：

```bash
docker compose logs balnana
```

<Aside type="tip">
	所有設定都附註解列在 `.env.example` 中。標示 `[admin]` 的設定之後也能在 `/admin` 修改，不必重新啟動。
</Aside>
