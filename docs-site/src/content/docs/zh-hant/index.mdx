	<Card title="用 Docker 啟動" icon="rocket">
		用 Docker Compose 一起啟動 Balnana 和 PostgreSQL，資料庫遷移會在啟動時自動執行。
	</Card>
	<Card title="在網頁上調整設定" icon="setting">
		開啟 `/admin` 就能調整大部分設定，不用重啟伺服器。進入前需要輸入管理員密碼。
	</Card>
	<Card title="選擇加入群組的方式" icon="open-book">
		用私人連結邀朋友加入，不用註冊。也能開啟帳號模式，透過密碼、Google 或 OpenID Connect 登入。
	</Card>
	<Card title="原始碼公開" icon="github">
		Balnana 採用 AGPL-3.0 授權，你可以查看、修改和分享原始碼。
	</Card>
</CardGrid>
